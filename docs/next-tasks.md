# 다음 작업 목록 (2026-11-23 기준)

현재 상태: v1 M1~M4 완료, M5 진행 중. 사용자 평가로는 기본 동작(한·영·일 자동 전환, 후보창, 일본어 Mozc 변환)은 원하는 대로 된다. 남은 것은 아래 순서로 진행한다.

## A. 바로 할 것 (작고 효과 큼)

1. **방향키로 후보 고르기** (사용자 요청)
   - 후보창이 열려 있을 때 ↓/→ 다음, ↑/← 이전.
   - 후보창이 없을 때의 방향키는 지금처럼 먼저 확정하고 앱에 넘긴다.
   - 손댈 곳: `backend/src/session.rs` `test`/`key` (VK_LEFT 0x25 ~ VK_DOWN 0x28).
2. **TIP 시간 초과 때 글자 유지**
   - 백엔드 응답이 200 ms를 넘으면 지금은 키를 놓쳐 조합이 어긋난다.
   - 시간 초과 시 친 키를 그대로 조합에 넣고, 다음 응답 때 백엔드와 다시 맞춘다 (`tip/src/client.rs`, `tip/src/lib.rs`).
   - Mozc 미리 띄우기(d859d97)로 주된 원인은 없앴으니 보험 성격.
3. **한국어 발음 → 한자 변환 (단어 단위)**
   - 한국어 토큰의 Shift 탭 후보창에 한자 후보를 덧붙인다 (학교 → 學校). 자동 변환 없음.
   - 데이터: libhangul `hanja.txt` (LGPL-2.1, GPL-3.0 프로젝트에서 사용 가능).
   - 고른 한자는 학습 기록에 남긴다.
4. **실사용 확인**
   - IME 켠 직후의 Shift 탭이 실제 키보드에서 괜찮은지 확인.
   - 백엔드 로그의 `slow request`를 모아 남은 지연 원인 확인 (작업 스케줄러 백엔드 로그는 Claude 셸에서 안 보이므로 사용자가 `%LOCALAPPDATA%\multilang-ime\backend.log`를 확인).

## B. 품질 (중간 크기)

5. **메모장 등에서 일본어 글자 깨짐**
   - 원인: 앱이 입력 중인 프로필의 언어로 글꼴을 고른다. 우리 TIP는 한국어 프로필이라 気·ー 등이 맑은 고딕으로 그려져 깨진다. `GUID_PROP_LANGID`는 무시된다.
   - 시험할 것: 일본어 구간을 넣을 때 같은 TIP의 일본어 프로필로 전환 (`ITfInputProcessorProfileMgr::ActivateProfile`). 조합이 끊기지 않는지, 전환 깜빡임이 없는지 확인.
   - 대안: 기본 프로필을 일본어로 (한국어는 조합 중에만 네모, 확정 후 정상).
6. **일본어 긴 단위 변환**
   - 문장 통째 변환이 문절별보다 낫다 (뉴스 글자 오류율 17.5→16.5%, Tatoeba 9.9→7.4%). 앞 문맥 넘기기는 효과 없음.
   - 일본어 구간은 Space에서 바로 확정하지 않고 구두점·Enter까지 조합으로 이어 가는 방식을 검토. Space=확정 원칙과 충돌하므로 사용자 결정 필요.
7. **긴 토큰 후보 품질**: 2위 이하 후보가 토큰 전체 단위라 질이 낮다. 구간(문절) 단위 후보 고르기.
8. **여러 문절 일본어 토큰**: 첫 문절 말고 다른 문절의 후보 고르기 (←→로 문절 이동 등, 1번 방향키와 키 배정 조율).

## C. 배포 준비

9. **라이선스 확정**: GPL-3.0-or-later 전제 (기획서의 "라이선스 미정" 갱신, LICENSE·THIRD-PARTY-NOTICES 작성: Mozc BSD-3, wordfreq 데이터 CC BY-SA 4.0, Rust 크레이트 MIT/Apache).
10. **Mozc 배포 방식**: 지금은 공식 MSI에서 꺼낸 mozc_server를 쓴다. Meltype처럼 Mozc를 직접 빌드한 도우미(stdin/stdout)로 바꾸면 실행 문제(가장 토큰, 패키지 앱 문맥)와 브랜딩이 풀린다. Bazel 빌드 30~40분.
11. **설치 프로그램**: TIP 등록(32/64비트), 언어 목록 추가, 작업 스케줄러 백엔드, 제거. Inno Setup 검토. 코드 서명.
12. **설정 화면 최소판**: 사용할 언어 선택, 자동 꺼짐 앱 목록, 학습 기록 지우기.
13. **자동 꺼짐**: 비밀번호·숫자 칸(InputScope), 관리자 앱, 게임.
