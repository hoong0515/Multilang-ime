# 앱별 실사용 확인표

설치판(v0.1.0 이후)으로 직접 쳐서 확인한 결과. 자동 입력 도구는 IME를 거치지 않으므로 모두 사람이 친 것이다.
항목: 자동 전환(한·영·일), 조합·후보창 위치, 왼쪽 Shift 탭(변환·후보), 한/영 고정과 알림, 비밀번호 칸 자동 꺼짐.

| 앱 | 입력칸 방식 | 결과 | 확인 |

| 문자표 | 옛 Win32 입력칸 (조합 창) | 정상 | 개발 중 |
| 카카오톡 (32비트) | 자체 입력칸 (조합 창) | 정상 | 개발 중 |
